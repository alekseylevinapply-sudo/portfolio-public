КОММЕРЧЕСКИЕ ПРОЕКТЫ

Задачи и мой вклад.

01 / СТРАХОВАНИЕ

Legal Case Microservices Platform

Ингосстрах · 2025–2026

Задача
Развитие backend-платформы для юридических процессов.
Мой вклад
Доработки Java-сервисов, миграции данных и процессов Camunda 7, устранение инцидентов, развёртывание и мониторинг.
Результат
Участие в запуске платформы в production и её последующем сопровождении.
  • Java 17
  • Spring Boot
  • Camunda 7
  • Kubernetes

02 / БАНКОВСКИЕ СИСТЕМЫ

Оркестратор корпоративных платежей

Иннотех / ВТБ · 2023–2024

Задача
Оркестрация B2B-платежей и интеграции с платёжными и банковскими сервисами в рамках импортозамещения.
Мой вклад
Разработка компонентов модульного монолита с Clean Architecture и элементами DDD; участие в BPMN-процессах Camunda 7. Saga, статусы операций, idempotency keys, ретраи с exponential backoff, компенсации и transactional outbox. Декомпозиция задач, code review, участие в технических собеседованиях и помощь коллегам при подключении к проекту.
Результат
В составе команды разрабатывал оркестратор платежей юридических лиц; в ходе развития проекта выделены отдельные сервисы. Пиковая нагрузка проектного контура из четырёх сервисов — около 1000 RPS.
  • Java 17–21
  • Spring Boot
  • Camunda 7
  • Kafka / Artemis
  • PostgreSQL / jOOQ
  • Liquibase
  • OpenShift

03 / ЛИЗИНГ

Телеметрия и новые backend-сервисы

Сбербанк Лизинг · 2020–2023

Задача
Перенос функций с Dynamics NAV: телематика, выбор поставщиков и оркестрация заявок. Телематический сервис — около 50 параметров со 100 000 устройств, опрос раз в сутки.
Мой вклад
Проектирование и разработка Java-сервисов с нуля, batch/ETL на Spring Batch. Событийный обмен вместо long polling, transactional outbox и rate limiting. Kafka, MinIO/S3; настройка CI/CD, Kubernetes/Helm и мониторинга вместе с командой.
Результат
Спроектировал два сервиса, один реализовал полностью. Участвовал в запуске и сопровождении нескольких экземпляров сервисов в Kubernetes-кластере из 3 нод.
  • Spring Batch
  • Kafka
  • PostgreSQL
  • MinIO / S3
  • GitLab CI
  • Helm / Kubernetes

04 / АВИАЦИЯ

Корпоративная интеграционная платформа

ЮТэйр · 2018–2020

Задача
Обмен данными между примерно 20 внутренними и внешними системами авиакомпании; около 100 интеграционных потоков.
Мой вклад
Java-сервисы, маршруты Apache Camel, преобразование XML/JSON и тестирование REST/SOAP-интеграций. Kafka topics, consumer groups, lag/offsets, manual commit, DLQ, retry/redelivery и throttling внешних API. Диагностика утечек памяти и соединений в омниканальном чате: GC-анализ и tcpdump.
Результат
Разрабатывал и сопровождал сервисы в составе команды интеграционной платформы; участвовал в переходе к Docker/Kubernetes.
  • Apache Camel
  • Kafka
  • REST / SOAP
  • ELK / Prometheus
