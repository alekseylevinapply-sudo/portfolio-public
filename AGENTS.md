# Правила работы с публичным портфолио

- Публиковать только проверенные профессиональные факты, согласованное резюме и разрешённые контакты.
- Не придумывать достижения, даты, показатели нагрузки, размеры команд и результаты проектов.
- Коммерческий опыт и собственные разработки описывать отдельно.
- Не добавлять приватные заметки, переписку, данные работодателей, секреты или неподтверждённые контакты.
- Первая публичная отправка новых персональных материалов требует явного подтверждения владельца после локального просмотра и проверки списка файлов.
- Публичные ветки `main` на GitHub и `pages` на Codeberg содержат один корневой коммит `init` с текущей версией. Перед заменой `main` сохранять прежнюю историю локально вне публичного репозитория; проверять список файлов и использовать только `--force-with-lease` с явно указанным ожидаемым SHA. Не переписывать другие репозитории и не отправлять резервные ветки или теги.
- Сайт — обычный HTML/CSS, JavaScript только при необходимости. Не добавлять аналитику, внешние виджеты или платные зависимости.
- Сборка копирует в `dist` только явно разрешённые файлы. Проверять ссылки, адаптивность, секреты и список будущего коммита.
- Проверять локальную Git identity перед коммитом. Не публиковать случайную личную почту в метаданных.
- Публикация на другие площадки настраивается отдельно по запросу владельца.
